# 小红书与抖音审核差异

这些是内容适配启发式规则，不替代平台最新公开规则。需要判断当前平台政策时，应实时核验官方来源。

## 小红书图文/视频

- 标题：是否具体、有真实利益点，并与正文兑现；避免只剩品牌口号。
- 封面：是否一眼看懂主题，产品露出与达人日常视觉是否协调。
- 正文：是否有可收藏的信息、真实场景或个人经验，而非连续堆卖点。
- 图片/镜头：顺序是否支持叙事，关键信息是否有对应画面证据。
- 关键词与话题：是否自然、准确、符合 brief；不要无关堆叠。
- 互动：结尾问题应与内容相关，避免机械索评或过度引流。

常见结构：结果/痛点钩子 → 生活场景 → 选择或使用过程 → 关键体验与卖点证据 → 适用人群/边界 → 自然互动。

## 抖音短视频

- 前段：尽快建立冲突、结果或观看理由；铺垫不能吞掉核心内容。
- 口播：按正常语速试读，避免书面长句和密集名词。
- 画面：每个重要卖点应有可拍摄、可理解的画面支持。
- 产品露出：出现时机清楚且不突兀，名称、包装、使用动作一致。
- 节奏：镜头、字幕、音效服务信息，不用空泛热闹掩盖内容。
- 结尾：行动引导与达人语气、平台场景匹配。

常见结构：强钩子 → 场景/矛盾 → 试用或解决过程 → 证据化卖点 → 结果/适用建议 → 行动引导。

## 视频可执行性

- 将“拍起来很好看”等抽象描述改为可执行镜头。
- 标记口播、字幕与画面不一致之处。
- 数字、专有名词和免责声明给足字幕停留时间。
- 无法从材料确定时长，不假定语速；建议真人试读并复核。
