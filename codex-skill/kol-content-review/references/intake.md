# 审核信息提取

## 最低输入集

从现有材料提取以下字段；找不到则标记“未提供”：

| 类别 | 字段 |
|---|---|
| 项目 | 品牌、产品、平台、内容形态、传播目标、目标人群 |
| Brief | 核心信息、卖点优先级、必带词、禁用词、话题/账号、行动引导 |
| 产品 | 官方名称、规格、成分/功能、使用方式、适用边界、价格与活动有效期 |
| 达人 | 从稿件提取达人姓名、小红书主页链接；采集后补充赛道、人设、常用开头、句式、内容节奏 |
| 交付 | 字数/时长、画面要求、发布时间、审核轮次、其他限制 |

## 证据优先级

发生冲突时不要擅自合并，按以下顺序标记来源并请求确认：

1. 本项目最新且明确的客户/品牌确认。
2. 最新版正式 brief 与产品资料。
3. 品牌官方公开信息。
4. 达人历史内容与用户补充描述。
5. 审核者推断。

日期不明或多个版本冲突时，列出冲突内容、各自来源和对稿件的影响。

## 达人识别与风格建模

优先从稿件抬头、文件名、备注与正文提取达人姓名和主页 URL。主页 URL 是唯一定位依据；只有昵称时，搜索结果同名或相似时必须请求用户确认。采集接口收费时，先给出预计调用量并等待明确确认。

读取达人主页近期公开内容后，提取而非臆测：

- 开头钩子类型：提问、反差、结果前置、生活片段、热点等。
- 叙事视角：经验分享、测评、教程、剧情、清单等。
- 语言特征：长短句、语气词、专业度、幽默方式、情绪强度。
- 内容节奏：铺垫长度、产品出现时点、镜头密度、结尾方式。
- 稳定标识：口头禅、固定栏目、场景、人物关系。
- 爆文结构：在当前样本中按互动表现识别代表内容，拆解标题钩子、开篇、信息展开、产品露出与收尾。
- 大纲匹配：将待审稿件的大纲顺序与上述稳定结构逐项对照，并保留历史内容证据链接。

样本不足时，只描述可见特征，并标注置信度低；不要创造“达人常用表达”，也不要把单篇爆文外推为稳定规律。
